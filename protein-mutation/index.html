Number residues in protein sequences and introduce point mutations interactively or via text notation (e.g. A20N,F54Y).

Mutation Editor

Click any residue to change it. Mutated residues are highlighted in amber.

Enter mutations separated by commas. Each mutation uses the format OrigAA Position NewAA (e.g. A20N,F54Y). The original amino acid is optional but will be validated when provided.

Format: [OrigAA]Position[NewAA] — e.g. A20N or just 20N or A20N,F54Y
