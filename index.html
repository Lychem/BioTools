🍀 BioTools

A collection of browser-based biological data analysis tools — no installation required.

Available Tools

🔬

Protein Structure → FASTA

Upload a PDB or mmCIF file and extract the amino-acid sequence as FASTA. Supports one-line and multi-line output.

Structure
🔄

CIF ↔ PDB Converter

Convert between mmCIF and PDB structure formats. Preserves atom coordinates, cell parameters, and symmetry information.

Structure
🔭

Protein Structure Viewer

Visualize PDB and mmCIF protein structures in 3D interactively. Upload a local file or fetch any entry directly from RCSB PDB by ID.

Visualization
🔗

Pairwise Sequence Alignment

Align two protein sequences with Needleman-Wunsch (global) or Smith-Waterman (local) using BLOSUM62, PAM250, or custom scoring.

Sequence
🔱

Multiple Sequence Alignment

Align multiple protein sequences using center-star progressive alignment with BLOSUM62. Visualize with Clustal, Taylor, hydrophobicity, or conservation color schemes.

Sequence
🔖

Antibody CDR Annotator

Identify CDR1/2/3 loops in VH/VL sequences using Kabat, Chothia, IMGT, Martin, or Contact numbering schemes. Fully client-side.

Antibody
🔯

Protein Mutation

Number residues in protein sequences and introduce point mutations interactively (click-to-mutate) or via text notation (e.g. A20N,F54Y). Outputs mutated FASTA.

Sequence
🔗

Interface Analysis

Analyze protein-protein interfaces: detect hydrogen bonds, salt bridges, hydrophobic, pi-stacking, pi-cation interactions. Compute buried surface area (ΔSASA) and identify epitope/paratope residues.

Structure
