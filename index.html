🧬 BioTools

A collection of browser-based biological data analysis tools — no installation required.

Available Tools

🔬

Protein Structure → FASTA

Upload a PDB or mmCIF file and extract the amino-acid sequence as FASTA. Supports one-line and multi-line output.

Structure
🔄

CIF ↔ PDB Converter

Convert between mmCIF and PDB structure formats. Preserves atom coordinates, cell parameters, and symmetry information.

Structure
🔭

Protein Structure Viewer

Visualize PDB and mmCIF protein structures in 3D interactively. Upload a local file or fetch any entry directly from RCSB PDB by ID.

Visualization
🔗

Pairwise Sequence Alignment

Align two protein sequences with Needleman-Wunsch (global) or Smith-Waterman (local) using BLOSUM62, PAM250, or custom scoring.

Sequence
